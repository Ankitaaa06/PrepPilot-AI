# 🤖 PrepPilot AI

An AI-powered Interview Preparation Assistant that analyzes resumes against job descriptions, calculates ATS scores, identifies missing skills, generates AI-powered resume feedback, prepares interview questions, provides an intelligent chatbot, and exports professional PDF reports.

---

# 📌 Features

✅ User Authentication (Login & Signup)

✅ Resume Upload (PDF)

✅ Job Description Upload (PDF)

✅ Resume Text Extraction

✅ Resume Cleaning & Processing

✅ Resume Chunking

✅ FAISS Vector Database

✅ ATS Score Calculation

✅ Resume Match Score

✅ Missing Skills Detection

✅ AI Resume Summary

✅ AI Interview Question Generator

✅ AI Chatbot (RAG Based)

✅ Analytics Dashboard

✅ PDF Report Generation

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/himanshibadoliya/PrepPilot-AI.git
```

Move into the project

```bash
cd PrepPilot-AI
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
streamlit run app.py
```

# 💡 How It Works

1. Login or Sign Up
2. Upload Resume
3. Upload Job Description
4. AI compares Resume with JD
5. Calculates ATS Score
6. Detects Missing Skills
7. Generates Resume Summary
8. Creates Interview Questions
9. Chat with AI Assistant
10. Download Professional PDF Report
